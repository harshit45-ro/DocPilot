# 📚 DocPilot

An AI-powered PDF Assistant built with Streamlit.

## Features

- Upload PDF files
- Extract text from PDFs
- Generate AI summaries
- Ask questions about PDFs
- Download summaries

## Tech Stack

- Python
- Streamlit
- PyPDF
- Groq API
- Llama 3.3 70B

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run chat_bot.py
```
